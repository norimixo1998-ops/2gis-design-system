# Каталог секций 2GIS Design System

Готовые HTML-шаблоны секций для AI-генерации страниц.

## Структура

components/
├── README.md ← этот файл
├── hero.html ← главный экран (в разработке)
├── features.html ← карточки возможностей (в разработке)
├── cta.html ← призыв к действию (в разработке)
├── footer.html ← подвал (в разработке)
└── examples/ ← примеры сборки страниц
└── README.md


## Как использовать

Каждая секция — это самостоятельный HTML-блок с CSS-переменными из дизайн-системы.

AI-инструмент (Open Design) берёт нужные секции из каталога и собирает из них страницу, заменяя только тексты.
